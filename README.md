# Instruxa

**Prompt infrastructure for ambitious AI teams.**

Instruxa is a premium prompt-engineering workspace for developers, startups, and organizations. It turns rough intent into structured, production-grade prompts for OpenAI, Anthropic Claude, Google Gemini, and other models.

[Open the live product preview](https://ai-prompt-engineering-platform.veerendra-kalyanbabu.chatgpt.site)

## Current MVP

- Interactive structured prompt compiler
- Audience and response-style controls
- Model-target selection
- Developer and business quick-start templates
- Quality and constraint summary
- Copy-ready prompt export
- Responsive premium SaaS interface
- Hybrid monetization model: included credits plus bring-your-own-key
- Proposed Free, Pro, Team, and Enterprise tiers

## Product direction

The roadmap includes authentication, encrypted provider-key storage, persistent projects, prompt versioning, evaluations, collaboration and approvals, metered AI credits, subscriptions, audit trails, SDK/API access, and enterprise controls.

## Technology

React 19, TypeScript, Tailwind CSS, shadcn/ui primitives, Lucide icons, and a Cloudflare-compatible runtime.

## Development

Run `npm ci`, then `npm run dev`. Validate with `npm run lint` and `npm run build`.

## Status

This repository contains the validated front-end MVP. Billing, authentication, persistent storage, and live LLM requests are intentionally not represented as production-ready until secure backend integrations are completed.
